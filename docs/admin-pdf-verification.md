# بررسی فایل‌های خروجی مدیریت

در ۲۰۲۶-۱۰-۰۸ خروجی واقعی برنامهٔ محلی `http://localhost:5090` با session حساب مدیر دریافت شد. پس از مسدودشدن دانلود اولیه توسط Chrome، ادامه با HTTP client انجام شد. بررسی end-to-end فرانت‌اند طبق آخرین دستور کاربر ادامه داده نشد.

## PDF

فایل‌ها در `output/admin-localization/` هستند و وارد Git نمی‌شوند. PDFها با PDFium رندر شدند؛ متن/فونت با pdfplumber خوانده و تصاویر رندرشده نیز مشاهده شدند.

| خروجی | فایل‌های بررسی‌شده | نتیجه |
|---|---|---|
| فاکتور تکی | invoice-jalali.pdf، invoice-gregorian.pdf | حروف فارسی متصل و خوانا؛ تاریخ ۱۴۰۵/۰۷/۱۶ و ۲۰۲۶/۱۰/۰۸؛ مبلغ/تعداد فارسی و SKU لاتین |
| فاکتور دسته‌ای | batch-jalali.zip، batch-gregorian.zip و PDF داخل آن‌ها | قرارداد ZIP حفظ شده؛ فایل‌های داخلی باز و رندر شدند |
| کاتالوگ | catalog-jalali.pdf، catalog-gregorian.pdf | ۱۰ صفحه در هر فایل؛ متن خوانا، شماره/قیمت/وزن فارسی و SKU لاتین؛ قالب تاریخ ندارد |
| بسته‌بندی | packaging-jalali.pdf، packaging-gregorian.pdf | شماره مرسوله/تعداد فارسی و SKU لاتین؛ قالب تاریخ ندارد |

فونت Vazirmatn تعبیه شده است. وارونگی تاریخ RTL، اعداد لاتین کاتالوگ و ترتیب واحد وزن پس از مشاهده خروجی اصلاح و فایل‌ها دوباره دریافت و مشاهده شدند. تغییرات فقط به transfer مدیریت محدودند.

سفارش `DEV-FA-0001` و مرسوله ارسال‌نشده `DEV-FA-PDF-0001` در پایگاه `nop_stationery_dev` fixture بررسی هستند. ایجاد fixture پرداخت، تغییر موجودی، ایمیل، پیامک یا تغییر وضعیت سفارش اجرا نمی‌کند. نمونه همهٔ حالت‌های نشانی، تخفیف و یادداشت را پوشش نمی‌دهد.

## Excel و XML

- sales-summary-jalali.xlsx و sales-summary-gregorian.xlsx با openpyxl فقط خوانده شدند. برگه نخست «گزارش فارسی» RTL است؛ خلاصه/تاریخ به‌ترتیب ۱۴۰۵/۰۷/۱۶ و ۲۰۲۶/۱۰/۰۸ را نمایش می‌دهند. برگه دادهٔ اصلی و فراداده VeryHidden `__NopCalendar` حفظ شده‌اند.
- orders-jalali.xml و orders-gregorian.xml با parser استاندارد XML خوانده شدند. ناسازگاری اعلان UTF-16 و بایت‌های UTF-8 خروجی بومی اصلاح شد. فایل شمسی `dateCalendar="jalali"` دارد؛ فایل میلادی عناصر و مقادیر تاریخ بومی را حفظ می‌کند.
- ورود مجدد فایل‌ها و همهٔ انواع گزارش اجرا نشدند؛ کنترل تقویم import و قرارداد افزونه‌ها در بازبینی مستقل کد بررسی شدند.

Build نهایی: صفر خطا و یک هشدار موجود CS0108 در کد تولیدشده EuropaCheckVatService. [بازبینی مستقل کد](admin-localization-review.md) ثبت شده است.
