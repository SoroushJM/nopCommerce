# Public storefront Persian resources

Source audit and pack validation: 2026-10-12. No database was modified or queried by this task. Existing QA databases may contain their own additional translations; these source counts do not measure their rows.

The existing `PersianAdminResourcesStartup` imports `PersianAdmin/fa-IR.admin.xml` at startup order 50. It creates the Persian language if missing and loads administrator translations, common labels, and a limited set of account labels. The file includes 608 non-`Admin.*` resources, mainly enums/activity/security. `Installation/installation.fa-IR.xml` translates installation screens; it is not a public-store language pack. Native `defaultResources.nopres.xml` supplies English resources, not a complete Persian public interface.

`PersianPublic/fa-IR.public.xml` adds 529 native Persian labels shared by both themes: the reported header/footer/newsletter gaps, catalog search/filter/paging, product prices/options/gift cards/rental/reviews/comparison, cart/coupons/totals/wishlist, checkout steps, customer account/address/password pages, orders and returns. Thirty native required-field messages are included. Brand names and administrator-authored menu/category/topic contents are data, not locale resources; this pack does not rename them.

`PersianPublicResourcesStartup` runs at order 51, after the administrator startup creates the language and before native culture setup at order 100. It reads the XML from the application's own `App_Data/Localization/PersianPublic` directory and calls native `ILocalizationService.ImportResourcesFromXmlAsync` with `updateExistingResources: false`. Native import skips every existing resource, inserts missing rows and invalidates locale caches. It does not replace administrator translations, copied English values, empty custom values, or deleted/changed language settings; the startup does not create or republish languages itself. A missing pack logs a warning and preserves existing language behavior.

Native Nop.Web publishing already copies `App_Data/**`, so this XML belongs in both independent packages. After merging, rebuild the plugin assembly to include the new startup and publish/copy the XML; dropping XML into an old plugin package alone does not run the importer. For already-running QA instances, restart the rebuilt isolated package to import missing labels into its own database copy. No additional SQL migration is needed for those keys. The unrelated `docker/madadrang-public-resources.sql` remains unchanged.

To import a reviewed complete translation pack without overwriting merchant choices, use the native service with `updateExistingResources: false`. The native administration import uses its configured update behavior; do not assume it preserves existing translations. The separate administrator baseline importer can update unchanged managed administrator translations by design; this public importer has a stricter missing-only policy.

Combined with the existing administrator file, source translations cover 1128 of 1718 native non-`Admin.*` resources. This is not a claim of a complete public Persian translation. The remaining 590 include account validation/privacy/security, cart warnings, shipment detail, vendor/private-message, blog, reward-point and other labels. Existing QA seed translations may already cover some. A complete language rollout should translate those remaining resources, validate formatting tokens, and inspect all enabled feature pages; an English missing-only fallback pack can make remaining untranslated pages readable while that work is reviewed.

Validation performed: the exact startup source compiles through a linked source in `Nop.Storefront.Tests`, with no new warnings. Four pure source-pack checks pass: unique known public keys and nonempty values; native format placeholders; native HTML link markup; required shared header/footer/catalog keys. No HTTP integration or database import was run by this agent, so database idempotence, startup registration in the rebuilt independent packages and rendered labels require parent QA evidence.
