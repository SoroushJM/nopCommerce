The distribution is unmodified and served locally. No CDN request is needed.
`persian-admin.js` supplies the nopCommerce Gregorian backing-field adapter,
Persian numerals, bounds validation and keyboard accessibility attributes.
Upstream owns calendar rendering, month/year controls and date/time selection.
The adapter adds Tab access, Enter/Space activation and arrow-key navigation
to upstream day controls; Escape uses the upstream hide API.
