> وضعیت پس از ادغام ۲۰۲۶-۱۰-۱۵: این نسخه‌های افزونه مرجع اجرا نیستند. طبق درخواست کاربر، کنترل‌های فارسی در ۲۱ مسیر اصلی `Areas/Admin/Views` قرار دارند و ثبت `AdminCalendarViewLocationExpander` برداشته شده است. ثبت دوبارهٔ آن بدون هماهنگی layoutها می‌تواند فرم ترجیح را تکرار کند. توضیح زیر مربوط به ساختار قبلی overrideهاست.

# تقویم فایل‌های مدیریت

این پوشه overrideهای Razor برای ۲۱ صفحهٔ بومی مدیریت را نگه می‌دارد. انتخاب تقویم، لینک‌های خروجی و فرم‌های ورود Excel در خود Viewها تعریف شده‌اند؛ کنترل یا لینک به‌صورت خودکار با JavaScript تزریق یا بازنویسی نمی‌شود.

`AdminCalendarViewLocationExpander` فقط برای اکشن‌های موجود در فهرست خود و کنترلرهای اسمبلی اصلی Admin فعال است. مسیرهای بومی برای partialها و templateهای دیگر حفظ می‌شوند. غیرفعال‌کردن افزونه مسیر بومی را باقی می‌گذارد؛ فایل‌های `Nop.Web/Areas/Admin/Views` تغییر داده نمی‌شوند.

`Shared/_AdminLayout.cshtml` یک wrapper کوتاه روی layout بومی است. فرم ترجیح تقویم را پس از محتوای صفحه و خارج از فرم‌های آن قرار می‌دهد. انتخاب‌گر خروجی با ویژگی HTML `form` به آن متصل است؛ import انتخاب مستقل و اجباری خود را دارد. ذخیرهٔ ترجیح در کنترلر `PersianAdminCalendarController` افزونه، با احراز دسترسی مدیر، اعتبارسنجی تقویم، antiforgery و بازگشت به آدرس محلی انجام می‌شود.

هنگام ارتقای nopCommerce، تغییرات ۲۱ View بومی باید در overrideهای متناظر نیز اعمال شوند. راهنما و قرارداد تقویم فایل‌ها در `docs/admin-file-calendars.md` است.
